# ♠️ Poker Room

Jogue poker **online** com baralho virtual ou controle **fichas, potes e blinds** na mesa presencial direto pelo navegador (PC e celular).

## ✨ O que tem no jogo

- **Modo Online** (baralho virtual, cartas 3D com flip, Flop/Turn/River animados, avaliação automática de mãos, potes laterais e showdown)
- **Modo Presencial** (baralho físico, controle rápido de fichas, potes, blinds e distribuição)
- **Sala DEV** para testar sozinho com 2 a 9 jogadores
- **Perfis com foto** e contas protegidas com Supabase
- **Múltiplos temas visuais** e **efeitos sonoros** integrados
- **100% estático** (HTML, CSS e ES Modules puros, sem build step)
